# 공학작문및발표 · 작문과제 06

GitHub Pages에 개인 포트폴리오를 배포하는 과제입니다. 김서연(syeoniism)의 관심 분야와 대표 프로젝트를 소개하며, HTML·CSS·JavaScript로 제작했습니다.

**배포 주소:** [포트폴리오 보기](https://syeoniism.github.io/portfolio-assignment06/)

## 주요 구성

- 자기소개, 관심 분야, GitHub 링크
- 프로젝트별 문제 정의, 담당 역할, 사용 기술, 결과
- 프로젝트 화면, 데모 및 소스 코드 링크
- 이력서 PDF 다운로드와 연락처

## 대표 프로젝트

| 프로젝트 | 소개 |
|---|---|
| BOOKUS | 책 교환과 독서 인증을 지원하는 Android 독서 모임 앱 |
| Career Balance | 문서 작성과 투표형 커뮤니티를 제공하는 취업 준비 웹 플랫폼 |
| Glass Slash | 다각형 절단과 면적 계산을 활용한 2D 브라우저 게임 |

## 실행 및 제출

`index.html`을 브라우저에서 열어 확인할 수 있습니다.

과제는 배포 URL만 적은 `김서연-공작과제-06.txt` 파일로 제출합니다.
